# 风格 23：纸灯影（Paper Lantern）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **灯箱即舞台 · 背光剪影层叠亮起 · 国风科普的深夜书房**
> 来源：参考视频第 04 种（Opus 5.5 风格盘点视频内演示；知识科普向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 4 条。

## 一、一句话认出它

画面主体是一盏点亮的纸灯箱，灯箱里层层叠叠的国风剪影（祥云、远山、村落、桂花、灯笼）从后往前依次被"点亮"，像有人在灯箱后面一盏盏开灯。前景是一张木桌，桌上有月饼和青花茶具。知识就写在灯箱下面的旁白里。

## 二、什么题目用它

国风知识科普、文化讲解、节气/节日内容、有"夜话"气质的慢讲解。10–30 秒讲一个知识点。

## 三、长什么样

- **背光层级（这是核心）**：场景是一个有 4–5 层的灯箱。最远层亮度最低、色最冷；每近一层亮度和暖度递增。亮点顺序 = 叙事顺序：先月亮 → 祥云 → 山 → 村落窗灯 → 桂花 → 红灯笼，最后镜头推进灯箱。
  - 层色温梯度：远山淡蓝 `#7a9cc6` @ `.25` → 村落窗灯暖黄 `#ffc93c` @ `.6` → 前景暖橙 `#ff9a4e` @ `.85`。
- **剪影语言**：所有层都是**单色剪影**，不带内部细节。村落只画窗格（一个个小方块亮着），桂花只画一簇簇小圆点，云只画轮廓。
- **灯箱本体**：暖白纸面 `#f5e6c8`，中心亮、边缘暗（径向渐变，中心 `#fff8e7`）。灯的边框是深色木框 `#4a3728`，带一点厚度和投影。
- **前景桌面**：木纹深褐 `#5c4033`，暗部几乎黑，只被灯箱照亮边缘。月饼（圆形 + 花纹）、青花茶具（白底青纹）作为"静物点缀"，不大幅动。
- **旁白排版**：灯箱下方细体竖排或横排小字，深色底上浅米字 `#e8dcc0`；不遮挡灯箱主体。
- **转场**：层与层之间用"点亮"而非切换——新层从 `opacity 0` 缓慢到全亮 12–16 帧，旧层不消失。镜头推进 = 灯箱放大占满画面。
- **节奏**：慢而稳。每层点亮间隔 1.5–2 秒。

## 四、技术实现方案

- 用 SVG `<g>` 分层，每层一个 `<path>` 剪影；层内元素用 `opacity` + `filter: blur(0.5px)` 做"背光发散"。
- **点亮动画**：不要直接淡入，用"先亮中心再扩散"——层内加一个径向渐变遮罩，`r` 从 0 涨到覆盖全层，配合 `opacity` 0→1，像灯从里面透出来。
- 灯箱整体加一层 SVG 滤镜：`feGaussianBlur` 小半径 + `feColorMatrix` 提亮，模拟纸的透光；粒子（桂花香氛感）用 20–30 个小圆点缓慢上浮。
- 木桌纹理用程序生成：若干条横向 noise 扰动 path + 低透明度深色叠加。
- 青花瓷纹样是唯一需要"精细"的元素，用重复的小 path（花瓣 + 藤蔓）拼出边缘装饰带。
- 帧率：灯箱层 24fps 平滑（光是连续的），前景静物 12fps 步进（手作感）。

## 五、声音

深夜环境底噪（很轻，`air` 总线）、点亮时一声极轻的 `click`/`switch`、桂花飘落配 `chime`（单音，延迟 0.4 秒混响）。旁白慢速、低声，像睡前讲述。无 BGM。

## 六、坑

- **层数不够就没有"灯箱"感**：少于 4 层会变成普通夜景插画。层与层之间要有明显的明暗阶梯。
- 别让前景桌面抢戏：桌面应该是暗的，观众的注意力必须被灯箱吸走。
- 亮灯顺序别乱：从远到近是物理逻辑（先开的灯在远处），反过来会像 bug。
- 国风元素别堆：祥云、山、村落、桂花、灯笼，选三四种就够，全堆上像素材展览。
