# 风格库

共 **34 套**风格。按 ID 或中文名称选择，只读对应说明和示例；画面预览见 [风格总览](风格总览.png)。

分两组：

- **A 组 · 内置 19 套**：随附可运行的 Remotion 示例工程，组件在 `src/styles/<id>/`。
- **B 组 · 沉淀 15 套（ID 从 20 起）**：来自外部参考视频的提示词 + 本 skill 补全的视觉规范，**尚无随附示例工程**，做片时按规格实现。

新片的工具选择见 [工具选择](工具选择.md)；工程能力与短板见 [工程规范](工程规范.md)；B 组提示词原文见 [Opus55提示词库](Opus55提示词库.md)。

前四个内置示例包含声音编排；其余内置示例是画面演示。风格文档中的声音建议需要在制作新片时落成 `sound.json`。B 组文档记载的参考视频和原片工具未随包提供，不视为本次已经验证的原片复现。

### B 组与 A 组的相邻风格

做片时注意区分，不要选错：

| B 组 | 相邻的 A 组 | 差别 |
|---|---|---|
| `pixelgame` | `pixel16`、`pixel` | 8bit 掌机感：色板 ≤24、精灵 16×16、12fps 逻辑帧、对话框即字幕 |
| `cyber` | `hud`、`synth` | 数据流 + 全息 + 故障，不做 retro 网格和地图面板 |
| `modeling` | `soft3d` | 建模流程演示，不是柔软质感展示 |
| `linev` | `line` | 9:16 竖屏 + 信息点密集 + 硬切节奏，横屏版在 `line` |

### B 组的示例工程

「图鉴示例」指 `projects/B组风格图鉴/`：一条 60 秒片子，15 段各 4 秒，每段一个 B 组风格的画面演示，顶部常驻序号/风格名/ID/字体，底部常驻该段提示词与出处。它**不是任何一部完整短片的范例**，而是 15 套风格的速览——用来快速对比选型，以及借每段的分层、坐标和组件。

```bash
node scripts/render.mjs --proj 'B组风格图鉴' --stills 2,6,10,14,18,22,26,30,34,38,42,46,50,54,58
node scripts/render.mjs --proj 'B组风格图鉴' --video
```

要按某个风格认真做片时，仍以该风格的文档为准；图鉴只证明了"这套规格能跑出画面"，没有证明它达到了参考视频的全部效果。

## 从视频沉淀的新风格

目前尚未登记用户参考视频的新风格。完成 [学习与验证](参考视频学习.md) 后，追加索引行，记录文档、实际实现与原创示例，并在文档中说明验证范围。保留 34 套已登记风格；候选方案只留在本地分析中。

新 ID 用简短的小写英文、数字或短横线，最长 64 字符。文档默认放 `references/风格_<id>.md`；Remotion 实现可放 `src/styles/<id>/`，示例放 `projects/示例_<id>/`。其他工具记录实际工程与脚本路径，无需伪造 TSX 入口。已有同名路径先读取：同一风格补充已验证方法；不同风格改用新 ID，保留原内容。

B 组风格在做片中沉淀出可复用组件后，把「当前实现」列从「图鉴示例」更新为实际路径，并在风格文档里补「已验证」说明。
