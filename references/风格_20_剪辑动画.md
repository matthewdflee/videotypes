# 风格 20：剪辑动画（Editor）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **手绘小人住在剪辑软件里 · 时间轴即世界 · 打工人纪录片**
> 来源：参考视频第 01 种（Opus 5.5 风格盘点视频内演示）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 1 条。

## 一、一句话认出它

一个手绘小人在剪辑软件的界面里活着：时间轴是他的地板，素材箱是他的仓库，他扛着素材奔跑、被预览窗口吸进去、从屏幕里探出来朝观众挥手。界面是真实剪辑软件的拟真复刻，角色是粗线条手绘小人，两者质感刻意拉开。

## 二、什么题目用它

职场共鸣、创作者日常、工具教程的开场钩子、"打工魂"类情绪短片。适合 10–30 秒的轻剧情，不适合长叙事。

## 三、长什么样

- **双层质感**：UI 层走拟真深色软件界面（暗灰 `#1e1e1e` / `#2b2b2b` 底、`#3c3c3c` 分割线、`#0f6bff` 选中蓝、`#ffc93c` 播放头），角色层走手绘（墨线 `#141414`、白纸填充、`#ff5a4e` 腮红/高光）。两层锐利度不同：UI 像素级精确，角色带抖动墨线和跳帧。
- **界面元素即舞台道具**：时间轴轨道 = 地面；素材缩略图 = 可搬运的货箱；播放头（黄线）= 剪刀或屏障；预览监视器 = 一扇能看到另一个世界的窗；波形 = 起伏的地形。
- **角色动作**：跑动用 6–8 帧循环；搬重物时身体前倾 15°、双腿变成小碎步；被吸入屏幕时先压扁再拉长成流星尾。
- **转场**：推进监视器画面进入下一镜（屏幕即门）；播放头扫过 = 硬切；拖拽素材到时间轴 = 新元素入场。
- **字**：界面内文字用等宽无衬线（`F.mono`）小号；标题和旁白用手写黑体，与角色同源。

## 四、技术实现方案

- **UI 用 DOM/SVG 精确绘制**，不要截图贴图——缩放和改分辨率时矢量保持锐利，且颜色参数可配置。时间轴轨道的缩略图条用程序生成的小色块阵列表示，不引入真实视频文件。
- **角色用 SVG path + 逐帧抖动**：`@styles/hand` 的 `jitter(seed)` 与 `stepT()` 可以直接复用——手绘层 12fps 步进，UI 层 30fps 平滑，两层的帧率差就是质感差。
- **关键帧对齐**：角色"击碎屏幕玻璃"这类动作，碎屑用 8–14 个三角碎片，各自带初速度矢量和重力，解析求解（`x = v·t`, `y = ½g·t²`），不要逐帧积分。
- **屏幕玻璃破碎**：先用一条主裂缝 path + 从中心点发散的 3 条次裂缝，再把区域三角化填白边。
- 深度层次：`z = [背景界面, 时间轴, 角色, 前景窗口边框]`，角色穿过窗口时需要在窗口边框后面（遮罩），别让角色浮在最上层。

## 五、声音

界面音效是灵魂：鼠标点击 `click`、素材拖入时间轴 `thunk`、播放头扫过 `whoosh`、玻璃碎裂 `shatter`（碎屑落地接一个 `clink`）。角色跑动配轻快的 `step` 两声交替。不要 BGM，或只用极轻的 lo-fi 底噪。

## 六、坑

- **UI 太干净会失去"软件感"**：必须有滚动条、隐藏的溢出内容、略微不对齐的面板——完全对称的界面像网页不像软件。
- 角色比例要小：占画面高度 1/4 左右，UI 才是主体。角色一大就变成"小人国 vlog"，失去工具纪录片的味道。
- 别让角色穿过自己够不到的高度；剪辑软件界面是有逻辑的空间，角色要遵守"素材在地上、监视器在桌上"的物理。
