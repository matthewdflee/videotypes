# 风格 28：水墨国风（Ink Wash）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **墨分五色 · 宣纸留白 · 一笔成形 · 晕染即转场**
> 来源：参考视频第 09 种（Opus 5.5 风格盘点视频内演示；文化意境向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 9 条。

## 一、一句话认出它

墨在纸上走：一笔画出塔，一笔画出柳，最后一笔升上夜空画成圆月。墨色有浓淡干湿，纸有大片留白，转场是一滴墨晕开。

## 二、什么题目用它

国风文化、诗词意境、节气/山水/建筑、品牌国风开场。10–30 秒。必须有"留白"的耐心，不适合信息密集的内容。

## 三、长什么样

- **五级墨色**（从浓到淡）：
  - 焦墨 `#1a1614`（主轮廓、重点）
  - 浓墨 `#3a3330`
  - 重墨 `#5c5250`
  - 淡墨 `#8a7f7c`
  - 清墨 `#b8afac`（远山、云雾）
- **宣纸底**：`#f2ead8`，带极轻的纤维纹理（细横线 noise，`opacity .06`）和四角微黄。
- **一笔成形**：每个物体由**一笔连续 path** 画出，用 `stroke-dashoffset` 从起笔到收笔揭示，0.8–1.5 秒一笔。落笔处墨稍浓（起笔重、行笔稳、收笔略顿）。
- **晕染**：墨块边缘不是硬边，而是向外渐淡 6–10px。实现：`feGaussianBlur` 小半径 + 一层更淡更大的同形 path 垫底。
- **留白规则**：画面至少 40% 是纸色。山水只画一角，塔只画一座，月只一轮。
- **节奏**：极慢。镜头之间留 1–1.5 秒"喘息"，让墨"干一干"。
- **转场**：一滴墨从中心晕开覆盖全屏，再淡出露出下一幕——16–20 帧。
- **字**：标题用楷体/宋体（Noto Serif SC），竖排，墨色，不加描边；落款可用小一号的红色印章方框（`#a83232`）。
- **色彩纪律**：全片近乎无色。参考提示词的"天空晕开淡青暮色、窗灯渐亮"是唯一的色——淡青 `#a8c0c8` @ `.3`、窗灯暖黄 `#ffc93c` @ `.5`，且只在结尾出现。

## 四、技术实现方案

```ts
// 一笔写成：path 按长度揭示，起笔处墨浓、收笔处略顿
const { evolvePath } = require('@remotion/paths');
const p = evolvePath(t, d, { length: totalLen });
// 用 evolvePath 返回的 strokeDasharray/strokeDashoffset 直接上 path

// 晕染：同形 path 垫两层，一层大而淡，一层小而浓
<path d={d} fill="#3a3330" opacity={.35} filter="url(#inkBlur8)" />
<path d={d} fill="#1a1614" opacity={.9} filter="url(#inkBlur2)" />
```

- 一笔的"起笔重"：path 首段用更粗的 `strokeWidth`（叠一条短 path），或起笔点放一个小墨点。
- 柳丝、云纹这类"多笔"物体，每笔间隔 0.15–0.2 秒依次写出，形成节奏。
- 晕开转场：一个不断扩大的不规则圆（noise 扰动边缘），`fill` 墨色，从 r=0 到覆盖对角线的 1.2 倍。
- 淡青暮色：结尾 3–4 秒内，一个 `#a8c0c8` 全屏矩形 `opacity` 0 → `.3`，窗灯逐个亮起。
- `post.json`：`{ "grain": 4, "vignette": .18, "bloom": 0, "ca": 0 }` —— 纸感颗粒可以有，但不要辉光（水墨不发光）。

## 五、声音

笔触 `brush`（毛笔摩擦纸的沙沙声，书写时持续）、收笔 `tap`（一声轻顿）、晕开 `ink`（低频的水感）、远处环境（风、水、寺院钟声，极轻）。旁白用慢速、低声、书面语文言腔。无 BGM。

## 六、坑

- **颜色一多就变成普通国风插画**：全片近乎黑白，唯一的色留给结尾。
- 留白不够 = 塞满 = 失去水墨的灵魂。宁可少画，不可画满。
- 晕染 blur 半径别超过 10px，否则像水彩不像墨。
- 一笔画完立刻接下一笔，没有"干笔"的停顿，节奏就散了——每笔后留 0.4–0.8 秒。
