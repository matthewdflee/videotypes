# 风格 29：数学讲解（Math Explain）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **公式逐步推演 · 图表随讲解生成 · 逐行高亮 · 答案是最后一行**
> 来源：参考视频第 10 种（Opus 5.5 风格盘点视频内演示；教育向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 10 条（源视频给的是品类定义与核心逻辑，未附完整提示词）。

## 一、一句话认出它

一块深色板面，公式从上到下一行行长出来，每行落定时被高亮一下，右侧同步画出对应的图表，最后一行是结论。观众能跟着一步一步看完推导，不跳过任何一步。

## 二、什么题目用它

数学/物理推导、算法讲解、财报拆解、任何"需要一步步看才懂"的内容。15–60 秒。

## 三、长什么样

- **底色**：深蓝黑 `#0d1420` 或暖深灰 `#16161a`，比纯黑柔和，长时间看不刺眼。
- **公式区**：居中偏左，占屏宽 55–65%；衬线数学体（KaTeX 风格 / Noto Serif SC + 数学符号），白色 `#f0f0f5`，当前行高亮。
- **逐行高亮**：新行落定时，该行背后一道柔和的浅色光带（`#f0f0f5` @ `.10`，blur 12px）从左扫到右 0.3 秒；同时该行 `opacity` 从 `.55` 升到 `1`。旧行保持 `.55`——观众永远知道推导走到哪了。
- **图表区**：右侧 30–40%，坐标轴细线（`#5a5a68`），曲线/柱体主色 `#4ea8ff`，强调点 `#ffc93c`。图表**跟着讲解长出来**：曲线按 path 从左画到右，柱体从底向上生长，标注点后出。
- **步骤编号**：每行左侧一个小的圆形或方形序号（`#4ea8ff` 底白字），让"第几步"始终可见。
- **收尾**：结论行用主色 `#ffc93c` 写出，落定时一次 8 帧的轻微缩放强调（1.0 → 1.04 → 1.0）。
- **转场**：硬切；不同题型之间用 6 帧的淡入淡出。
- **字幕**：旁白走底部常规字幕位，不与公式区重叠。

## 四、技术实现方案

- **公式用 HTML 排版不用图片**：KaTeX/MathJax 输出 SVG，矢量清晰、可动画。Remotion 里用 `dangerouslySetInnerHTML` 注入 KaTeX 输出即可（KaTeX 需进依赖）。
- 逐行落定 = `<Series>` 里每个 `<Series.Sequence>` 的 `from`；高亮光带是一个绝对定位的 div，`x` 由帧号驱动。
- 曲线"长出来"：`evolvePath()` 按长度揭示；柱体生长：`scaleY` 从 0 到 1，`transform-origin: bottom`。
- 标注点（"这里取得最大值"）后出：曲线画完后 0.3 秒，一个 `#ffc93c` 圆点 + 引线 + 文字弹入。
- 步骤序号与行绑定，同一行只在一个文件里定义一次时间。
- `post.json`：`{ "grain": 0, "vignette": .12, "bloom": .1, "bloomThreshold": .75, "ca": 0 }` —— 教育片要干净，后期越少越好。

## 五、声音

每步落定 `tick`（音高随步骤数上行，形成"在前进"的感觉）、图表画完 `swell`（短）、结论落定 `chime`（清亮三音）。旁白匀速、清晰，句间留 0.4 秒。无 BGM。

## 六、坑

- **一次出现太多行**：同时可见不超过 5 行公式，超过就分屏或分批。
- 图表和公式不同步是最大违和——图表必须严格跟着对应公式的出现时机长出来。
- 别用浅色底：深色底 + 高对比公式是教育视频的通用解法，浅色底在屏幕上易读性差。
- 推导过程别自动跳过：宁可加时长，不要为了赶时间把两步并成一步。
