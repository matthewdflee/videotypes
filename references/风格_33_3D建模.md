# 风格 33：3D建模（3D Modeling）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **线框 → 实体 → 材质 → 拆解 · 360° 旋转展示 · 结构标注**
> 来源：参考视频第 14 种（Opus 5.5 风格盘点视频内演示；技术/展示向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 14 条（源视频给的是品类定义与核心逻辑，未附完整提示词）。
> 与内置风格 `soft3d`（3D渲染）的差别见 [风格库](风格库.md)。

## 一、一句话认出它

一个物体从一堆发光的线框开始，线框逐渐"实体化"长出表面，然后材质贴上去，最后部件拆开、各自标注名称，转一圈展示。观众看到的是"一个东西是怎么被造出来的"。

## 二、什么题目用它

产品结构讲解、机械原理、建筑/工业设计、科学模型（分子、器官、地形）、技术发布会中的结构环节。15–45 秒。

## 三、长什么样

- **四阶段流程**（全片的主线，顺序固定）：
  1. **线框**：物体只有线框，`#00f0ff` 或 `#61afef`，线宽 1px，缓慢自转。
  2. **实体化**：表面从底部向上"长出"（或按部件顺序点亮），线框保留但变淡，实体面半透明。
  3. **材质**：表面 `opacity` 升到 1，材质参数（粗糙度、金属度）在 0.5 秒内从默认过渡到目标值，高光出现。
  4. **拆解 + 标注**：部件沿轴向外平移 8–15%，每个部件旁一条引出线 + 名称标签。
- **相机**：物体居中，匀速自转（20–30 秒一圈）+ 相机极缓的推轨。拆解阶段相机略微拉远（因为物体变宽了）。
- **标注**：引出线 = 从部件中心到标签的一条折线（先直后横），端点一个小圆点；标签用半透明深色底 + 白字小号。标签跟随部件移动（不闪不跳）。
- **背景**：深色 `#0a0a12` 渐变 + 地面接触阴影（一个柔和的椭圆）。可加极淡的网格地面（`#1a1a2e`）增强空间感。
- **转场**：阶段之间用 8–12 帧淡入淡出，或线框"闪一下"（亮度脉冲）作为阶段开始的信号。
- **节奏**：四阶段各占 20–30%，别在某一阶段停留过久。

## 四、技术实现方案

- **路线选择**（见 [工具选择](工具选择.md)）：
  - 简单几何体（盒子、圆柱、拼接体）→ `@remotion/three` + Three.js 程序化生成，时间轴完全可控。
  - 复杂模型/真实材质/全局光照 → Blender 离线渲染序列帧，再用 Remotion/FFmpeg 合成字幕和标注。**离线渲染时把标注留到合成层做**，别在 Blender 里排字。
- 线框 → 实体：`material.wireframe` 从 `true` 渐变为 `false` 不可行——做两套 mesh（一个 `wireframe: true`、一个实体），实体的 `opacity` 0 → 1、线框的 `opacity` 1 → `.15`。
- "表面长出"：用 shader 的 `vPosition.y` 做阈值（`if (vPos.y < growY) opacity = 1`），`growY` 由帧号驱动；或简单用 clip plane。
- 拆解：每个部件是一个 `<group>`，`position.x/y/z` 按 `interp(frame, [f0, f0 + 24], [0, offset])` 平移。
- 标注跟随：把 3D 坐标用 `camera.project()` 转成屏幕坐标，标签用绝对定位 div 渲染——别用 CSS 3D transform，投影会让字变形。
- `post.json`：`{ "grain": 2, "vignette": .2, "bloom": .25, "bloomThreshold": .62, "ca": .8 }`。

## 五、声音

线框出现 `hum`（电子嗡鸣，贯穿第一段）、实体化 `materialize`（上升的合成音）、材质就位 `shimmer`（清亮的金属感）、拆解 `unfold`（机械展开的低频）、标注弹出 `tick`。无 BGM。

## 六、坑

- **离屏渲染的视频和字幕对不齐**：先把离线镜头的帧数、FPS、起始帧写进 `beats.json`，再排字幕，别估。
- 标注文字被 3D 投影变形——用 2D 屏幕坐标渲染标签。
- 拆解方向不统一（有的往左有的往右）会显得乱；沿各自局部轴、方向一致地散开。
- 自转速度过快会让观众看不清结构；一圈至少 20 秒，拆解阶段可以暂停自转只做拆解。
