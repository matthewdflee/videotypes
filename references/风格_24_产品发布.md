# 风格 24：产品发布（Product Launch）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **深色触控板就是画布 · 微距扫光 · 3D 英雄镜头 · 字砸屏收尾**
> 来源：参考视频第 05 种（Opus 5.5 风格盘点视频内演示；商业 3C 向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 5 条。

## 一、一句话认出它

黑色画布上，一束微距扫光掠过产品边缘；随后产品 360° 旋转展示，四种配色依次切换；功能点做成两张卡片依次砸入；最后产品名一个大字砸屏，落在网址按钮上。整体像苹果发布会砍到 7 秒。

## 二、什么题目用它

3C/数码产品发布、功能演示、App Store 预览片头、品牌开场。7–20 秒，短而狠。

## 三、长什么样

- **底色**：深炭黑 `#0a0a0a` 到 `#141414` 的极缓渐变，带极轻的辉光。产品是唯一亮源。
- **扫光**：一道 45° 的窄高光（宽 8–12% 画面）以 0.8–1.2 秒扫过产品边缘，光带用 `#ffffff` @ `.8` + 大半径 blur。扫过时产品轮廓被"擦亮"。
- **3D 英雄镜头**：产品悬浮、缓慢自转（约 15–20 秒一圈），相机微推。底部一道柔和的椭圆接触阴影。旋转用 `@remotion/three` 或程序化绘制（简单几何体可直接 SVG）。
- **配色切换**：不做淡入淡出，做"光扫过时换色"——扫光带经过的瞬间 product 的 `fill` 切到下一个色值，扫光走后新色已稳定。这是本风格最标志的一招。
- **功能卡**：深色玻璃卡片（`#1c1c1e` @ `.9` + 1px `#ffffff` @ `.12` 描边 + 圆角 24px），图标 + 一行标题 + 一行小字。入场用 `0 → 1.06 → 1` 的过冲，间隔 0.35 秒错峰。
- **字**：产品名用几何无衬线粗体（Space Grotesk / Noto Sans SC 800），字号占屏宽 30–40%；功能卡标题 500 字重，正文 400。字砸屏 = 从 1.4 缩到 1.0，8 帧内完成，配 `E.snap`。
- **收尾**：大字落定 → 0.3 秒后网址按钮从下方滑入（胶囊形，`#0f6bff` 底白字），停 1.5 秒。
- **转场**：全部硬切 + 砸屏。不要淡入淡出——发布会的节奏是"切"。

## 四、技术实现方案

```ts
// 扫光扫过即换色：由扫光带的 x 位置决定当前 product 用哪个配色
const sweepX = interp(frame, [f0, f0 + 36], [-W * .3, W * 1.3], E.inOut);
const colorIdx = Math.min(COLORS.length - 1, Math.floor(lerpInv(sweepX, -W * .2, W * 1.2) * COLORS.length));
const color = COLORS[colorIdx];
```

- 扫光带本身：一个倾斜的亮色矩形，`filter: blur(28px)`，叠在产品之上用 `mix-blend-mode: screen`。
- 简单几何产品（手柄、方块、圆柱）直接 SVG + 渐变即可；需要真实光影的用 `@remotion/three` + `soft3d` 的 SDF/材质模块。
- 字砸屏用 `spring({ frame, fps, config: { damping: 12, stiffness: 200 } })`，从 scale 1.4 回 1.0，比 linear 缩放有力得多。
- `post.json`：`{ "grain": 3, "vignette": .2, "bloom": .22, "bloomThreshold": .7, "ca": .8 }` —— 商业片要一点辉光和色散，但别加颗粒感太强。

## 五、声音

扫光 `swoosh`（低通滤波的上升音）、配色切换 `tick`（极短，像快门）、功能卡砸入 `thud`（低频，配轻微的下坠感）、产品名砸屏 `impact`（低频 + 一点混响）、按钮滑入 `click`。无 BGM——发布会节奏靠音效撑。

## 六、坑

- **没有扫光的产品发布片只是幻灯片**：扫光 + 换色是本风格的签名动作，一定要有。
- 字体别用衬线体；产品名用衬线会立刻失去 3C 感。
- 别加中文书法体或手写体——商业发布片的字必须是几何无衬线。
- 功能卡超过三张就散；7 秒片最多两张卡，20 秒片最多四张。
