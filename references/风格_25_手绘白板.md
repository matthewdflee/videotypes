# 风格 25：手绘白板（Whiteboard）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **问题写满白板 · 荧光笔划重点 · 答案是最后一句话**
> 来源：参考视频第 06 种（Opus 5.5 风格盘点视频内演示；知识/方法论向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 6 条。

## 一、一句话认出它

一块白板，上面陆续手写出问题和选项，一支荧光笔划过重点，最后写下结论。镜头是俯拍白板的固定视角，偶尔轻微推近。像有人在白板前给你讲一件事，讲完你只记住被划重点的那句。

## 二、什么题目用它

方法论讲解、决策框架、清单式内容、观点输出。10–40 秒。核心结构：**抛出问题 → 堆可能性 → 划重点 → 给结论**。

## 三、长什么样

- **白板本体**：微暖白 `#f4f4f0`，带极轻的板材纹理和一道擦不净的旧笔痕（`#d8d8d0` @ `.35`，很淡）。四角有轻微暗角，像被相机拍到的板面。
- **手写笔迹三档**：
  - 正文：黑 `#1a1a1a`，中粗，行笔有起笔重、收笔轻的变化。
  - 问题/选项：深蓝 `#2b4a8f`，稍细，可以带一点潦草（写得快）。
  - 荧光笔：半透明色块，宽 = 字高的 1.1 倍，颜色 `#ffd93c`（黄）/ `#a8e6a1`（绿）/ `#ffb3c6`（粉）。**荧光笔必须画在字的下面**（先有色块后有字），且边缘有毛糙感。
- **书写动画**：字按笔画顺序"长"出来，不是整字淡入。每字 0.4–0.8 秒，笔画用 `stroke-dasharray`/`stroke-dashoffset` 逐段揭示。
- **擦除**：结论出现前，旧内容用一道从左到右的擦除痕抹掉（一个白色矩形 + 毛边扫过），不是淡出。
- **镜头**：固定俯拍，`scale` 在 1.0 → 1.06 之间极缓推近；结论落定时可以有一次 0.15 秒的快推（1.0 → 1.12 → 1.05）。
- **转场**：擦除（同板内）+ 硬切（换板/换场景）。
- **字**：手写黑体（得意黑手写版 / Smiley Sans），字间距略大于印刷体，允许轻微的高低不齐。

## 四、技术实现方案

- **逐笔画书写**是硬需求。两条路：
  1. 用 `@remotion/paths` 的 `evolvePath()`，按路径长度揭示 SVG path——适合准备好的图形。
  2. 对文字，把每个字拆成 2–4 段 path（横、竖、撇、点），各段依次 `strokeDashoffset` 从 length 到 0。
- 荧光笔层必须在文字层之下：`<g>` 顺序 = `[荧光笔块, 文字]`。色块边缘用 noise 扰动 path 做毛糙。
- 擦除用一个 `clipPath` 矩形，`x` 从 0 涨到 W，配一条 4px 的浅灰阴影边。
- 手写抖动：每条 path 叠 1–2px 的 noise 位移，**只在收笔处加**，行笔中段要稳，否则像帕金森。
- 帧率 24fps 平滑；书写本身不要跳帧（跳帧会让字看起来在抖而不是在写）。

## 五、声音

笔尖摩擦 `pen`（持续的轻噪音，书写时音量和速度跟随笔画速度）、荧光笔划过 `marker`（更闷、更低）、擦除 `erase`（短促的白噪音）。结论落定时一个轻 `tick`。无 BGM。

## 六、坑

- **整字淡入是最常见的错误**：白板风格的全部可信度都建立在"字是一笔一笔写出来的"上。
- 别写太满：白板上同时最多 5–6 行，超过就显得乱，观众读不完。
- 荧光笔不要划整句话——划 2–4 个字才有"重点"的感觉。
- 别用印刷体字体；手写体选错（选了行楷而不是板写黑体）会显得刻意。
