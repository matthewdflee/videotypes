# 风格 34：线条竖屏（Line Vertical）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **9:16 竖屏 · 极简线条 · 快节奏转场 · 信息点密集输出**
> 来源：参考视频第 15 种（Opus 5.5 风格盘点视频内演示；社交平台向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 15 条（源视频给的是品类定义与核心逻辑，未附完整提示词）。
> 与内置风格 `line`（线条动画）的差别见 [风格库](风格库.md)。

## 一、一句话认出它

竖屏、线条、快。一个接一个的极简图形和短句，每条信息 1.5–3 秒，转场几乎不留喘息。刷到的人会在第三条信息点前决定要不要看完。

## 二、什么题目用它

抖音/快手/视频号的知识卡片、观点输出、清单式内容、金句轮播。15–45 秒。**这是 15 种新风格里唯一默认竖屏的**。

## 三、长什么样

- **画幅**：1080×1920（9:16）。安全区：上下各留 12%，左右各留 8%——避开平台 UI（头像、点赞、文案、进度条）。
- **三区布局**（自上而下）：
  - 顶部 0–20%：序号/标签（"01 / 05"）+ 主标题（最多两行）。
  - 中部 20–72%：主视觉区，线条图形在这里。
  - 底部 72–100%：字幕行（40px）+ 极简水印/账号名。
- **线条语言**：1–3 个元素同时存在；描边粗细 4–6px @1080p；颜色单色（`#f5f5f5` 深底用 / `#141414` 浅底用）+ 一个强调色（`#ff2d95` 或 `#0f6bff`）。线条带"发光轮廓"（外描边模糊 8px 同色），暗底上更明显。
- **信息节奏**：每 1.5–3 秒一个信息点。图形先入场（0.4 秒）→ 文字点后出（0.2 秒后）→ 停留 0.6–1 秒 → 硬切下一个。
- **转场**：硬切为主；图形之间可用"线条重连"（旧线条淡出、新线条从同一起点画出，0.3 秒）。**不要淡入淡出超过 6 帧**——竖屏用户的耐心以秒计。
- **强调**：关键词用强调色 + 一次 4 帧的缩放脉冲；数字用大号字（占屏宽 30%）+ 弹入。
- **入场动效**：全部用 `spring`，`damping: 14` 左右的干脆回弹，不要长缓动。

## 四、技术实现方案

```ts
// 竖屏项目：Composition 的 width/height 必须是 1080×1920
export const W = 1080, H = 1920;
// 信息点用数据驱动，改文案不用改组件
const POINTS = [
  { icon: 'circle', title: '第一件事', body: '先做最重要的那件', accent: true },
  ...
];
// 每个点一个 Series.Sequence，时长由 perPoint 决定
```

- 用 `@styles/line` 的描线与发光轮廓组件，但把布局改成竖屏三区。
- `vo.json` 驱动的字幕走底部区；`perChar: 0.10`、`base: 0.5`——竖屏字幕要比横屏更快（停留时间短）。
- 安全区用一个常量 `SAFE = { top: .12, bottom: .12, left: .08, right: .08 }`，所有元素约束在内。
- 节奏用 `beats.json` 写 `T('p1')`、`T('p2')`…，每个点 2 秒；改节奏只改 beats 不改组件。
- `post.json`：深底 `{ "grain": 0, "vignette": .12, "bloom": .2, "bloomThreshold": .65, "ca": 0 }`；浅底全部归零。

## 五、声音

每个信息点入场 `tick`（音高随序号上行，形成"进度感"）、强调词 `pop`、转场 `whoosh`（很轻）。无 BGM——竖屏信息流里突然来音乐很违和。

## 六、坑

- **忽略安全区**：底部字幕被抖音的文案区和进度条盖住，是竖屏最常见的翻车。
- 节奏拖：一条信息超过 3 秒，完播率就掉。宁可删内容，不要拖时间。
- 竖屏别用横屏的构图思维（左右分栏在 9:16 里显得挤）；竖屏是上下叙事。
- 淡入淡出超过 6 帧 = 节奏断；竖屏只用硬切 + 短 spring。
