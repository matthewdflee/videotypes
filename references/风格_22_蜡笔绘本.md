# 风格 22：蜡笔绘本（Crayon Book）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **蜡笔颗粒质感 · 水彩晕染天空 · 翻页即转场 · 手写片名**
> 来源：参考视频第 03 种（Opus 5.5 风格盘点视频内演示；原示例片《月亮睡不着》）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 3 条。

## 一、一句话认出它

看起来真是用蜡笔在纸上画出来的：线条有颗粒感和断续，色块有蜡的覆盖力（叠色会变深），天空是水彩横扫出来的晕染，最后画面缩回成一本书，封面就是片名。整体是"睡前故事"的语气。

## 二、什么题目用它

儿童内容、睡前故事、治愈向短片、温情品牌片。语气必须软，不适合快节奏和硬广。

## 三、长什么样

- **颜色**：低饱和的粉彩系。推荐底色：奶油纸 `#f7ead7`；主色：薰衣草 `#9b8fd4`、蜜桃 `#f4a58c`、鼠尾草绿 `#8fb996`、雾蓝 `#8db4d8`；夜色：群青 `#3d4f8f`、深靛 `#2a3260`。**不要纯黑**，夜色用深靛；**不要高饱和荧光色**。
- **蜡笔质感三要素**：
  1. 线条 = 主线 + 2–3 条偏移 1–2px 的半透明副线，颜色略浅，模拟反复涂抹。
  2. 填充 = 底色上叠 3–5 层半透明色片，每层边缘不规则（用 `@remotion/noise` 的 `noise2D` 扰动 path），模拟蜡的颗粒堆积。
  3. 边缘留白 = 手绘填充常常填不满，形状内缘露出 1–2px 纸色。
- **水彩天空**：`#8db4d8` → `#3d4f8f` 的横向渐变上，叠 2–3 个大半径、低透明度的不规则色团（`gblur` sigma 40+），边缘用 noise 扰动。
- **白蜡笔星星**：纸底上不"画"星星，而是用纸色/白色小圆点 + 短十字，亮度高于底色——像用白蜡笔在彩纸上擦出来的。
- **转场**：**翻页**是最标志的——当前画面像书页一样从右往左下翻，露出下一页，转场 16–20 帧，带纸的弯曲阴影。
- **字**：手写体标题（得意黑手写版或 Smiley Sans），笔画边缘加 1px 纸色描边，像写在纸上的；正文旁白用圆体小字。
- **节奏**：慢。每个镜头至少 2.5 秒，元素入场用 12–16 帧的缓出，禁止弹跳和快切。

## 四、技术实现方案

```ts
import { noise2D } from '@remotion/noise';
import { PAPER } from '@styles/paper';   // 纸纹与剪边可复用

// 蜡笔线条：主线 + 两条抖动副线
const crayon = (pts, color, w = 5) => (
  <g strokeLinecap="round" fill="none">
    <path d={d(pts)} stroke={color} strokeWidth={w} />
    <path d={d(pts.map(p => [p[0] + 1.5, p[1] + 1]))} stroke={color} strokeWidth={w * .6} opacity={.35} />
  </g>
);

// 蜡笔填充：多层半透明 + noise 扰动边缘
const crayonFill = (shape, color, t) => shape.map((_, i) => (
  <path key={i} d={jitter(shape, i * 1.7, 3)} fill={color} opacity={.22} />
));

// 翻页转场：三层纸页叠放，middle 页做 rotateY 翻转
```

- 纸张纹理用 `@styles/paper` 的纸纹叠加层，`opacity` 压到 `.12`，蜡笔风要软。
- 翻页转场用 CSS `transform: rotateY()` + `perspective`，但**角度必须由帧号计算**（`rotateY(${ease(frame, 0, 18)}deg)`），不能用 transition。
- 渐变天空不要用 SVG `linearGradient` 的硬边，用 5–6 个横向色带，每带之间用小位移 blur 过渡。
- 帧率用 12fps 的 `stepT()` 步进角色，24fps 平滑翻页——颗粒感来自低帧率，别全片都用 30fps。

## 五、声音

铅笔沙沙 `crayon`（持续的轻噪音，像在画画）、翻页 `page`（关键转场）、夜晚环境音（很轻的蟋蟀）。旁白用气声、慢速，句间留 0.8 秒以上。

## 六、坑

- **饱和度一高就变成儿童塑料玩具广告**：粉彩的关键是"灰"，每个颜色都掺一点纸色。
- 蜡笔质感做过头（线条抖得太乱）会像"故障艺术"而不是"手作"——抖动量控制在 1–2px。
- 别用弹跳、缩放冲击这类动效；蜡笔世界的物理是"慢慢的、有重量的纸"。
- 群青夜空里用白蜡笔画星星，不要用黄色星星——黄星在蓝底上太跳。
