# 风格 30：赛博数字（Cyber Digital）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **霓虹数据流 · 全息投影 · 故障艺术转场 · 深色底高饱和荧光**
> 来源：参考视频第 11 种（Opus 5.5 风格盘点视频内演示；科技/数据向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 11 条（源视频给的是品类定义与核心逻辑，未附完整提示词）。
> 与内置风格 `hud`（赛博朋克HUD）、`synth`（复古Synthwave）的差别见 [风格库](风格库.md)。

## 一、一句话认出它

深色背景上，数据像发光的流体一样流动：数字雨、全息投影的旋转线框、故障抖动的文字。整体不是"科幻电影"，而是"数据可视化仪表盘的电影化"。

## 二、什么题目用它

AI/大数据/云计算内容、安全与监测、技术概念可视化、科技产品片头。10–30 秒。

## 三、长什么样

- **底色**：近黑深蓝 `#050810` 或 `#0a0512`，带极轻的径向亮斑（左上或中心）。
- **荧光三组**（按主次选用，全片不超过三组同时出现）：
  - 主青 `#00f0ff`
  - 主品红 `#ff2d95`
  - 辅绿 `#39ff88` / 辅黄 `#ffd93c`
- **数据流三件套**：
  1. **数字雨/流**：竖向的细条或数字串，自上而下流动，速度 200–400px/秒，透明度沿流衰减。
  2. **全息投影**：物体的线框（wireframe）以半透明 + 扫描线叠加呈现，缓慢旋转；加一道横向扫描线（`#00f0ff` @ `.3`，高 2px）自上而下循环扫过。
  3. **粒子网络**：30–60 个小点，间距小于阈值时连线，透明度随距离衰减。
- **故障艺术（glitch）**：转场和强调时用。三个通道（R/G/B 或三组荧光色）各自水平偏移 4–12px，持续 4–8 帧；配 2–3 条横向撕裂带（`#00f0ff` @ `.5`，高 3–6px，随机 x 位置）。
- **HUD 元素**：角标括号、十字准星、细线圆环、读数文本（等宽字体 `F.mono`，小号，`#00f0ff` @ `.8`）。
- **文字**：科技感无衬线（Space Grotesk / Noto Sans SC），主标题可加轻微外发光（`text-shadow` 0 0 12px 同色），但**发光半径别超过 16px**。
- **转场**：故障抖动（主）+ 数据流冲刷（一道亮带横扫覆盖，露出下一幕）。

## 四、技术实现方案

- **确定性随机**：所有粒子/雨滴位置用固定 seed 的伪随机（`noise2D(x * .01, seed)` 或预生成数组），**禁止 `Math.random()`**——否则 Studio 预览和渲染结果不一致，且同一次渲染的两次输出不同。
- 全息线框：Three.js 的 `wireframe: true` 材质 + `@remotion/three`，或 SVG 多 `<line>` 手绘（简单几何体）。
- 扫描线：一个 2px 高的矩形，`y = (t * speed) % H`，用 `mix-blend-mode: screen` 叠加。
- 故障：把内容复制三层，分别套 `filter: url(#rShift)` / `url(#gShift)` / `url(#bShift)`（`feOffset` 水平位移），再叠回原层；故障只在 `t % 3 < 2` 的帧启用，其余帧正常——持续的故障会让人疲劳。
- 粒子网络连线：O(n²) 即可（n≤60），每帧重算；连线的 `opacity = 1 - dist/threshold`。
- `post.json`：`{ "grain": 2, "vignette": .25, "bloom": .35, "bloomThreshold": .55, "bloomRadius": 24, "ca": 1.2 }` —— 本风格是少数适合较强辉光和色散的，但 vignette 别太重。

## 五、声音

数据流 `data`（持续的电子嗡鸣，低频）、故障 `glitch`（短促的数字噪音爆破）、扫描线 `scan`（很轻的高频）、全息出现 `holo`（上行的合成音）。旁白用偏低、稳定的语调。可选极轻的电子 BGM（默认不做）。

## 六、坑

- **荧光色超过三种就会变成游乐场**：控制同时出现的主色数量。
- 粒子用 `Math.random()` 是隐蔽的坑——Studio 里看着对，渲染出来位置全变。
- 发光半径过大（>20px）会让文字糊掉，可读性归零。
- 别把所有元素同时打开：数字雨 + 全息 + 粒子网络 + 故障，一次只用两三个，留呼吸空间。
