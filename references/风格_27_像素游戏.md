# 风格 27：像素游戏（Pixel Game）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **8bit 游戏实况 · 对话框即字幕 · 背包与道具即叙事**
> 来源：参考视频第 08 种（Opus 5.5 风格盘点视频内演示；趣味剧情向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 8 条。

## 一、一句话认出它

看起来就是一台 8bit 掌机正在运行的游戏：小人在像素地图上行走，头顶弹出对话框，背包里拿出道具递给同伴。字幕就是游戏对话框，道具就是叙事道具。

## 二、什么题目用它

游戏化叙事、团队/伙伴故事、"打怪升级"式能力讲解、轻松向科普。10–30 秒。

## 三、长什么样

- **色板**：严格 16–24 色。参考提示词的两个镜头（雪地出发、围炉取暖）需要的色：
  - 雪地：`#e8f0f8` / `#c8d8e8` / `#90a8c0`
  - 木剑/木箱：`#8b5a2b` / `#6b4423` / `#a87038`
  - 火焰：`#ff6b35` / `#ffc93c` / `#ff3b20`
  - 角色：`#f4d8b0`（肤）/ `#2b4a8f`（衣）/ `#141210`（线）
- **像素纪律**：所有元素按 4px 或 8px 网格对齐，禁止非整数坐标。角色精灵 16×16 或 24×24 格，行走动画 4 帧循环（站立/抬左脚/站立/抬右脚），**每帧保持 6–8 帧停留**（48–64ms）。
- **对话框**：底部或头顶的像素边框矩形（`#f8f8f0` 底 + 3px `#141210` 描边，四角有小方块装饰），文字用 8px 像素字体（FusionPixel），逐字显示，每字 2–3 帧。**对话框就是字幕**，不要另加一行字幕。
- **地图**：俯视或 45° 等轴， tile 化。远景用低对比度色块表示，不做细节。
- **道具交互**：背包打开 = 一个 2×3 网格的道具栏弹出；拿出道具 = 道具从格子飞到手上（4 帧瞬移 + 2 帧停留，不做补间）。提示词"冷吗？给，一起围着"= 角色 A 从背包拿出木柴/火把，场景切换到围炉，火焰从无到有一帧帧长出来。
- **转场**：硬切 + 一次 4 帧的白闪（像游戏过场）。火焰"长出来"用逐帧绘制（每一帧多几簇火苗），不用淡入。
- **UI 元素**：血条/体力条（左上，分段像素块）、道具名浮现的小标签。

## 四、技术实现方案

```ts
import { PIXEL16 } from '@styles/pixel16';   // 16位像素的网格与精灵系统可直接复用
const S = 4;  // 一个游戏像素 = 4 屏幕像素
const px = (v) => Math.round(v / S) * S;   // 所有坐标过这个函数

// 精灵动画：按帧号取帧，帧内保持
const frame = Math.floor(t * 12);        // 12fps 逻辑帧
const pose = POSE_CYCLE[Math.floor(frame / 6) % POSE_CYCLE.length];
```

- **复用 `pixel16`（风格 17）** 的网格对齐和调色板机制，但本风格是 8bit 掌机感：色板更少（≤24）、精灵更小（16×16）、逻辑帧率更低（12fps）。
- 精灵不要用雪碧图切片——用二维字符串数组定义，便于改色和复用：
  ```ts
  const HERO_DOWN = ['..1111..', '.122221..', ...];  // 数字索引进调色板
  ```
- 对话框逐字：`text.slice(0, Math.floor(t * charsPerSec))`，末尾跟一个闪烁的光标方块（`Math.floor(t * 4) % 2`）。
- 火焰逐帧生长：预生成 6 帧火焰形态，按 `Math.floor(t * 8)` 取帧，帧之间硬切。
- 全片 `imageRendering: 'pixelated'`，`post.json` 关掉一切后期：`{ "grain": 0, "vignette": 0, "bloom": 0, "ca": 0 }`。

## 五、声音

8bit 音效必须是方波/三角波合成的：对话框文字 `blip`（每字一声，音高随机但不超五度）、道具获得 `arpeggio`（上行三音）、火焰 `crackle`（循环的爆裂噪音）、过场白闪 `whoosh`。可选极轻的 chiptune BGM（本风格是少数适合配乐的，但默认仍不做）。

## 六、坑

- **非整数坐标是头号杀手**：一个 1px 的偏移就会让整片从"像素游戏"变成"模糊的低清动画"。
- 别加抗锯齿、别加辉光、别加胶片颗粒——像素风必须硬边。
- 精灵动画别用 30fps 补间，看起来会是"滑步"；用 12fps 硬切。
- 对话框别做成现代 UI（圆角、玻璃拟态），必须是 8bit 的方角、粗描边。
