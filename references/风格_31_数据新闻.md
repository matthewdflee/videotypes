# 风格 31：数据新闻（Data News）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **图表动态生成 · 重点数据标注 · 新闻标题式排版 · 时间轴推进**
> 来源：参考视频第 12 种（Opus 5.5 风格盘点视频内演示；资讯/财经向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 12 条（源视频给的是品类定义与核心逻辑，未附完整提示词）。

## 一、一句话认出它

像电视台的数据新闻栏目：屏幕上方一条新闻标题，中间一张会"长出来"的图表，关键数字用大号字砸在旁边，底部一条时间轴标出事件推进。

## 二、什么题目用它

财经解读、行业报告、社会趋势、政策影响、任何"数字说话"的资讯内容。15–60 秒。

## 三、长什么样

- **底色**：浅色为主。纸白 `#f5f5f2` 或极浅灰 `#eef0f3`；也可做深色版（`#0d1420`），但同片内不混用。
- **新闻标题区**：顶部 18–22% 高度。栏目标签（小胶囊，`#d92b2b` 红底白字，如「数据看板」）+ 主标题（Noto Sans SC 800，占屏宽 85%，最多两行）+ 一行来源小字（`#8a8a92`，400 字重，写数据来源和年份）。
- **图表区**：中部 45–55%。柱状图/折线图/环形图，主色 `#1f5fd0`（蓝），强调系列 `#d92b2b`（红，仅用于"要说的那个数"），其余 `#b8bcc4`。坐标轴细线 `#c8ccd4`，网格线 `#e4e6ea`。
- **数字大字**：关键数字从图表旁砸入——Noto Sans SC 900，字号占屏宽 20–35%，颜色 = 该数据所属系列色。落定时一次 8 帧缩放强调。
- **时间轴**：底部一条水平线 + 3–6 个节点圆点；当前节点高亮放大，过去节点实心、未来节点空心。旁白推进到某个时间点时，高亮节点右移。
- **标注**：图表上的引出线（细线 + 端点圆点）+ 小字说明，指向被讲解的那个数据点。
- **转场**：图表之间用 8–10 帧淡入淡出 + 轻微上移；不同新闻点之间硬切 + 标题区刷新动画（旧标题上移消失，新标题下方进入）。
- **字幕**：底部常规字幕位，不遮挡时间轴。

## 四、技术实现方案

- **图表手写 SVG，不引图表库**：柱状图 = 若干 `<rect>`，`scaleY` 从 0 到 1、`transform-origin: bottom`，柱间错峰 0.04 秒；折线图 = `evolvePath()` 按长度揭示；环形图 = `stroke-dasharray` 动画。可控、无依赖、逐帧确定。
- 数据放在项目根的 `data.json`，组件读文件渲染——改数据不用改代码。
- 数字大字砸入用 `spring({ damping: 14, stiffness: 220 })`，配 6 帧的一次性 `bloom` 闪光。
- 时间轴节点高亮：`T()` 锚点驱动，`scale` 1.0 → 1.4 → 1.2。
- 标题刷新：`<Series>` 里两个 `<Series.Sequence>`，旧的做 `y: 0 → -40` + `opacity → 0`，新的做 `y: 40 → 0`，各 8 帧。
- `post.json`：`{ "grain": 0, "vignette": .08, "bloom": .08, "bloomThreshold": .8, "ca": 0 }` —— 新闻要干净可信，后期几乎不加。

## 五、声音

图表生成 `draw`（短促的上升音）、数字砸入 `impact`（中频，干脆）、时间轴节点移动 `tick`、标题刷新 `swipe`。旁白用新闻播报式语速，匀速、略快。无 BGM。

## 六、坑

- **数据必须标来源**：每张图配一行来源小字（机构名 + 年份）。没有来源的数字不要上屏——这是新闻和营销的分界线。
- 图表同时超过两张就散；一屏一个图表 + 一个数字。
- 强调色（红）只给"要说的那个数"，给多了就没有重点。
- 数字别四舍五入到看不出变化；该用千分位就用，该保留小数位就保留。
