# 风格 26：黑白版画线刻贴纸（Engraving Sticker）

> 示例状态：**尚无随附 Remotion 示例**。本文档由外部参考视频的提示词与画面描述沉淀而来，是制作新片时的规格来源，不是已验证的原片复现。

> **黑白版画 · 线刻密度即明暗 · 白色模切描边 · 纸胶带贴标题**
> 来源：参考视频第 07 种（Opus 5.5 风格盘点视频内演示；人文/历史向）。
> 提示词原文见 [Opus55提示词库](Opus55提示词库.md) 第 7 条。

## 一、一句话认出它

图像全部由排线和点刻组成——没有灰阶，明暗全靠线条的密度和方向。物体带一圈白色模切描边，像从纸上抠下来贴在背景上的贴纸。标题贴在一张撕边纸卡上，四角压着半透明胶带。

## 二、什么题目用它

历史人文、地理风物、航海/贸易/旅行叙事、复古印刷气质的内容。10–30 秒。

## 三、长什么样

- **只有两个值**：墨黑 `#141210` 和纸白 `#efe9dc`。中间调完全由排线（hatching）产生：
  - 暗部：交叉排线（45° + 135° 叠加），线距 3–4px。
  - 中间调：单向排线，线距 6–9px。
  - 亮部：点刻（stippling），点径 1.5–2px，间距 8–12px。
- **排线方向跟着形体走**：船帆用横向线（风）、水面用长横线、山石用斜向短线。方向统一比密度准确更重要。
- **模切描边（die-cut）**：每个主体外轮廓外扩 6–8px 的纸白色描边，描边本身带轻微的手撕不规则（noise 扰动 1–2px）。
- **投影**：贴纸右下方一道 6px 偏移的柔和深色投影（`#141210` @ `.18`，blur 4px），让元素"浮"在纸上。
- **标题纸卡**：撕边纸卡（上下边缘是手撕的不规则曲线），纸色 `#e8dfc9`，略深于背景；四角各一条半透明纸胶带（`#d4c9a8` @ `.55`，旋转 ±8°，带竖向纹理）。
- **构图**：极简，每个镜头 1–2 个主体，大量留白。参考提示词的三个镜头——威尼斯帆船启航、丝绸之路驼队、元大都宫殿与线装游记——都是"一个主体 + 一句标题"。
- **入场**：12 帧定格弹入（`0 → 1.08 → 1`），落定后完全静止，不做持续动画。**贴纸不会飘**。

## 四、技术实现方案

```ts
// 排线：按形体轮廓生成一组平行线，用 clipPath 裁进形体
const hatch = (shape, angle, gap, offset) => (
  <g clipPath="url(#clip-shape)">
    {lines.map((l, i) => <line key={i} x1={l.x1} y1={l.y1 - i * gap} x2={l.x2} y2={l.y2 - i * gap} stroke="#141210" strokeWidth={1.2} />)}
  </g>
);
```

- 排线生成：把形体放进 `<clipPath>`，在 clip 内画一组平行 `<line>`，通过 `clipPath` 的 `transform: rotate(angle)` 换方向。这是最可控的做法，比手画 path 快得多。
- 点刻：在形体 bbox 内随机撒点（固定 seed），用 clipPath 裁掉外部，暗部提高密度。
- 撕边纸卡：矩形上下边替换成 noise 扰动的 path（`noise1D(x * .01, seed)` 偏移 4–8px）。
- 纸胶带：圆角小矩形 + 竖向细纹理（几条 1px 半透明线）+ `opacity .55`。
- 帧率：**12fps 步进**（`stepT()`），贴合"版画印刷"的定格感。贴纸弹入后保持静止。

## 五、声音

纸张摩擦 `paper`、贴纸落下 `stick`（一声闷响 + 一点胶带的粘滞感）、翻纸 `page`。旁白用偏低的女声或男声，慢速，像纪录片。无 BGM。

## 六、坑

- **出现灰色就是失败**：任何渐变、半透明叠加（除了投影和胶带）都会破坏版画感。中间调必须靠排线密度。
- 排线间距不均匀会立刻显得廉价——用等距，只在形体边缘做自然收尾。
- 别让贴纸动起来：本风格的力量在于"静止的图像 + 定格的节奏"，加漂浮动画会变成普通贴纸风。
- 标题别用印刷黑体无衬线——配一个衬线体（Noto Serif SC）或老式打字机体，才有 19 世纪出版物的味道。
